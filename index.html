RubricAI

Automates grading and plagiarism analysis for Google Classroom assignments using Gemini for nuanced theory and code review, with student code run and tested in sandboxed Docker containers. Plagiarism detection goes past keyword matching — semantic similarity for theory answers, AST-normalized comparison for code so simple variable renaming doesn't slip through. Celery + Redis handle analysis in the background, and finished reports are emailed straight to students.
